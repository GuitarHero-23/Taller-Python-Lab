Complejidades:
  Ejercicio 1: Complejidad O(N) (lineal). Rcorre n elementos uno por uno para ingresar los números en la lista. Igualmente, recorre cada elemento con sum() para sumarlos.
  Ejercicio 2: Complejidad O(N) (lineal). Recorre la lista una sola vez para encontrar el número mayor y el número menor.
  Ejercicio 3: Complejidad O(N) (lineal). Recorre la lista un elemento a la vez hasta encontrar una coincidenica o hasta terminar la lista. En el peor caso se revisan n elementos de la lista, por lo que el tiempo de ejecución crece directamente en función de n. 
  Ejercicio 4: Complejidad O(N^2) (cuadrática). Recorre la lista n veces, haciendo que crezca cuadráticamente el número de elementos para ordenar.
  Ejercicio 5: Complejidad O(log n) (logaritmico). Cada iteracion el numero se divide para 2, lo que reduce el tamaño del problema por la mitad. 
  Ejercicio 6: Complejidad O(N^2) (cuadrática). Recorre la lista q veces, haciendo que crezca cuadraticamente el número de elementos a comparar.
